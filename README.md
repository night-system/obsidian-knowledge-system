# obsidian-knowledge-system

配置驱动的 AI 知识系统框架。聚焦"连接配置 + 两个测试工具"，并为后续接入 LLM 知识系统预留可配置入口。v0.2.0 起新增：独立**设置视图**（通过命令面板 "Show Knowledge System settings view" 打开为普通标签页）、**动态输出属性**（键值对，可增删）、以及**测试工具**标签页。

---

## 功能简介

- **一键配置 DeepSeek**：在【连接】标签页填写 API Key 后，点击「测试并获取模型」按钮会调用服务商 `GET /models` 接口，并用返回结果自动填充下方模型下拉框。**模型列表完全来自接口返回，不硬编码任何模型名**。
- **源/输出文件夹**：支持输入框 + 文件夹选择器（Obsidian 原生 Suggest），方便在 vault 内任意选择目录。
- **自定义时间属性**：可配置读取文件时间所用的 frontmatter 属性名和 moment 时间格式；留空则使用文件创建时间（`ctime`）。
- **动态输出属性**：输出属性改为键值对形式，可自由添加/删除"属性名 → 默认值"行（时间戳、来源为固定行），改设置后新生成的文件使用新属性名。
- **独立设置视图**：命令面板 "Show Knowledge System settings view" 可在普通标签页中打开同一套设置 UI（与设置页一致）。
- **测试工具标签页**：在设置页第 5 个标签页内一键执行「统计最近文件数」「输出最新内容测试」两个测试操作（不再占用命令面板）。
- **本阶段不调用 LLM 生成内容**，仅提供配置与测试操作；API 相关内容为后续阶段预留。

## 安装

### 方式一：BRAT（推荐）

1. 安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 插件。
2. 打开 BRAT，选择 **Add Beta plugin**，粘贴仓库地址：

   ```
   https://github.com/night-system/obsidian-knowledge-system
   ```

3. 添加后，在 设置 → 第三方插件 中启用 **obsidian-knowledge-system**。

### 方式二：手动

将以下三个文件放入 vault 的插件目录（没有则新建）：

```
<你的 vault>/.obsidian/plugins/obsidian-knowledge-system/
  ├── main.js
  ├── manifest.json
  └── styles.css
```

然后在 设置 → 第三方插件 中启用。

## 使用步骤

设置页顶部为 **Tab 布局**（`连接` / `文件夹` / `时间` / `输出属性` / `测试工具`），每个标签页内的设置沿用"分组折叠 + 顶部搜索"：点击分组标题可折叠/展开，搜索框按设置项名称与描述实时过滤当前标签页的条目。

1. 打开 **设置 → obsidian-knowledge-system**（或在命令面板运行 **Show Knowledge System settings view** 以标签页打开独立设置视图）。
2. 在【连接】标签页填写 **API Key**，点击 **测试并获取模型**，从下拉框选择默认模型（`自定义服务商` 为其中的可折叠分组）。
3. 在【文件夹】标签页设置 **源文件夹** 和 **输出文件夹**。
4. 在【时间】标签页设置 **时间属性名**、**时间戳格式**、**最近 N 天**。
5. 在【输出属性】标签页设置 **时间戳属性名**、**来源属性名**，并在动态键值对行中添加"属性名 → 默认值"（如 审核状态 → 未审、分类 → 未分类），或点击 **+ 添加属性** 新增。
6. 在【测试工具】标签页点击 **统计最近文件数** 或 **输出最新内容测试** 执行对应操作。

## 设置项说明

### 连接（标签页）

| 名称 | 说明 | 默认值 |
|---|---|---|
| API Key | DeepSeek 或自定义服务商的 API Key（掩码显示）。 | 空 |
| 测试并获取模型 | 调用 `GET /models` 并填充下方下拉框；401/403 提示"API Key 无效"，402"余额不足"，429"限流"。 | — |
| 默认模型 | 可用的模型列表，来自服务商接口。 | 空 |

### 自定义服务商（连接标签页内，默认折叠）

| 名称 | 说明 | 默认值 |
|---|---|---|
| Base URL | OpenAI 兼容服务的基础地址。 | `https://api.deepseek.com` |
| API Key | 自定义服务商的 API Key（预留）。 | 空 |
| 模型 | 自定义服务商的模型 ID（预留）。 | 空 |

### 文件夹（标签页）

| 名称 | 说明 | 默认值 |
|---|---|---|
| 源文件夹 | 统计最近文件数时扫描的文件夹。 | `/` |
| 输出文件夹 | 输出最新内容测试生成文件的文件夹。 | `/` |

### 时间（标签页）

| 名称 | 说明 | 默认值 |
|---|---|---|
| 时间属性名 | 读取文件时间使用的 frontmatter 属性名；留空则用文件创建时间。 | 空 |
| 时间戳格式 | moment 兼容的时间格式（如 `YYYY-MM-DD`）。 | `YYYY-MM-DD` |
| 最近 N 天 | 统计最近文件数时回看的天数。 | `7` |

### 输出属性（标签页）

输出时 frontmatter 由**固定行**与**动态键值对**组成：

| 名称 | 说明 | 默认值 |
|---|---|---|
| 时间戳属性名 | 写入输出文件的当前时间戳属性名（固定行）。 | `created` |
| 来源属性名 | 写入输出文件的来源路径属性名（固定行）。 | `source` |
| （动态行）属性名 | 输出文件的 frontmatter 属性名（键值对，可添加/删除）。 | — |
| （动态行）默认值 | 该属性写入输出的默认值。 | — |
| + 添加属性 | 新增一条"属性名 → 默认值"行。 | — |

> 旧版 `审核状态属性名/默认值` 与 `分类属性名/默认值` 会在首次加载时自动迁移到上面的动态行（`approved → 未审`、`category → 未分类`）；旧字段仍保留读取兼容。

### 测试工具（标签页）

| 名称 | 说明 |
|---|---|
| 统计最近文件数 | 扫描源文件夹，统计最近 N 天内的 Markdown 文件数，以 Notice 提示。 |
| 输出最新内容测试 | 取源文件夹时间最新的文件，将其正文最后 100 个字符（按 Unicode 字符计，含换行）写入输出文件夹，并生成含可配置属性名的 frontmatter。 |

## 命令

命令面板仅保留打开设置视图的一项：

| ID | 名称 | 作用 |
|---|---|---|
| `show-knowledge-system-settings-view` | Show Knowledge System settings view | 以普通标签页打开设置视图。 |

> 原先的「统计最近文件数」「输出最新内容测试」已移至【测试工具】标签页，命令面板不再注册。

> 输出的文件 frontmatter 示例：

```yaml
---
created: 2026-08-25
approved: 未审
category: 未分类
source: notes/example.md
---
（源文件正文最后 100 个字符）
```

## 移动端说明

- `isDesktopOnly: false`，可在 Obsidian 移动端运行。
- 网络请求仅使用 Obsidian 原生 `requestUrl` 通道，不依赖 `fetch` 或 Node 的 `http` / `fs` / `path`。
- 文件夹选择器使用 Obsidian 原生 `AbstractInputSuggest`（设置页、命令、Notice 在移动端均正常）。
- 不使用任何桌面端专属 API，也不引入运行时依赖。
